Session: Bops v1.1.5 — Add %bops_balance_whole% and %bops_balance_commas% to BopsPlaceholderExpansion
Date: 2026-06-10
-------------------------------------

Goal:
  Fix %bops_balance_whole% showing as literal text in TAB scoreboard. Root cause:
  balance_whole and balance_commas were only present in BitsLegacyExpansion, not in
  BopsPlaceholderExpansion. TAB was configured to use %bops_*% (not %bits_*%),
  so the missing case returned null and PAPI left the placeholder unparsed.

What Changed:

  BopsPlaceholderExpansion.java
    - New switch case: "balance_commas" → fmtCommas(balance) (alias for balance_formatted)
    - New switch case: "balance_whole" → fmtWhole(balance)
    - New private helper fmtWhole(double v):
        Uses Math.floor() to truncate (never rounds up)
        Casts to long, then formats with NumberFormat (Locale.US, groupingUsed=true)
        Min/max fraction digits = 0 so no decimal point appears
    - getVersion() bumped 1.1.4 → 1.1.5

  BitsLegacyExpansion.java
    - getVersion() bumped 1.1.4 → 1.1.5 (keeps PAPI version cache fresh; logic unchanged)

  BopsPlugin.java
    - Startup log updated to list all five bops placeholders

  build.gradle.kts
    - version = "1.1.5"

  plugin.yml
    - version: '1.1.5'

Full Placeholder List After This Change:

  BopsPlaceholderExpansion (identifier "bops"):
    %bops_balance%           — trailing zeros stripped (e.g. 1542.87 or 100)
    %bops_balance_formatted% — commas + 2 decimal places (e.g. 1,542.87)
    %bops_balance_commas%    — alias for balance_formatted
    %bops_balance_raw%       — always 2 decimal places, no commas (e.g. 1542.87)
    %bops_balance_whole%     — whole number only, comma-grouped (e.g. 1,542)

  BitsLegacyExpansion (identifier "bits") — unchanged:
    %bits_balance%           — same as bops_balance
    %bits_balance_formatted% — same as bops_balance_formatted
    %bits_balance_commas%    — same as bops_balance_commas
    %bits_balance_raw%       — same as bops_balance_raw
    %bits_balance_whole%     — same as bops_balance_whole

Jar Path:
  build/Bops-1.1.5.jar

What to Test In-Game:
  1. Replace Bops-1.1.4.jar with Bops-1.1.5.jar in plugins/ and restart server.
  2. Confirm startup log: "PlaceholderAPI support enabled — %bops_balance%, %bops_balance_raw%, %bops_balance_formatted%, %bops_balance_commas%, %bops_balance_whole% active."

Command Reference:
  /bits                          — show own balance (players only)
  /bits balance [player]         — check balance; [player] requires bits.admin
  /bits pay <player> <amount>    — transfer to online player; can't pay self
  /bits give <player> <amount>   — bits.admin: add to any player (online or offline)
  /bits take <player> <amount>   — bits.admin: remove from any player
  /bits set <player> <amount>    — bits.admin: set balance exactly (0 or more)

Permissions:
  bits.admin — defaults to op; gates give/take/set and balance-check-other

Storage:
  File: plugins/Bits/balances.yml
  Format: YAML, key = UUID string, value = long
  Saved on: every give/take/set/pay command, and on plugin disable
  Loaded on: plugin enable

Config:
  plugins/Bits/config.yml
  settings.starting-balance: 0   (balance returned for players with no record)

Assumptions / Constraints:
  - Balances are non-negative longs. setBalance clamps to 0 if given negative.
  - deposit() clamps at Long.MAX_VALUE (overflow guard).
  - /bits pay requires the target to be online.
  - /bits give/take/set work on offline players via server's offline player cache.
  - No Vault. No economy API. No integrations of any kind.
